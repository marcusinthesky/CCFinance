# 03. Plan the sections and exhibits

## Goal

Give each of the eight section files a question and a specific job.
See the [section and exhibit map](section-map.md) for the shared argument and both layout budgets.

## Acceptance

- [x] Write the paper’s argument in reading order, one sentence per section. Start with the researcher trying to reconstruct a sample, follow a captured article through selection, dating, issuer linking and focus, then show what researchers can learn at the publisher, bank-pair and firm-session scales. For each handoff, name the new capability or open question the next section takes up. Verify historical sequence against the evidence wherever the prose claims one.
- [x] Budget the FinFM technical pages so a reviewer reading only the main paper can identify the contribution, evaluation population, strongest evidence, material limitation and artifact access. Assign a reader question to each main exhibit.
- [x] Make a section map from abstract through appendices, covering access, prior corpora, construction, validation, coverage and replications. Assign the abstract and conclusion their own takeaways.
- [x] Place each proposed table or figure beside the question it answers. Record its source, unit and denominator, and decide which supporting detail belongs in the appendix.
- [x] Before paragraph outlining, record the overall length target and any venue limits, citing the rules for what counts toward each limit. Label editorial targets as provisional wherever a venue leaves length open.
- [x] Give each of the eight sections a target prose word count and an estimated page allocation in each layout (fractional pages are fine). Include space for exhibits, captions, front matter and references. Show main-text and appendix totals separately and reconcile each layout to its budget.
