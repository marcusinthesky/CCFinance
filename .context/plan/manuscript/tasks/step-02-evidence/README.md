# 02. Map claims to evidence

## Goal

Assemble the evidence needed to defend the paper’s claims.
Use the [enrichment evidence map](enrichment.md) for primary-source exhibits, existing results and proposed follow-up studies.

## Acceptance

- [ ] Map the reader questions in the venue brief to a result, an artifact or an explicit evidence gap. Check especially what a reader can rebuild, which labels were judged independently of predictions and which timing assumptions support retrospective evaluation.
- [ ] Link each proposed claim about access, scale, source selection, enrichment quality and coverage to a primary source or frozen output. Identify which artifacts readers can download or rebuild and the applicable licence for each.
- [ ] For each replication, record the benchmark version, sample, estimator, substitutions, uncertainty and unresolved details. Mark unsupported claims for qualification or removal.
